# Ping Pong Game

# Description
- Players can control bars that are on opposite sides of the bar and try to keep the ball from getting past the bars.

# How to play
- Player 1: W/S Keys
- Player 2: Arrow Keys

# Features
- Two player game
- Moving ball
- Bar controls
- Score tracker
- Reset button
- Background button

# Tools
- HTML
- CSS
- JavaScript
- https://www.colorhexa.com/
